Pair support

Pair connects your existing coding agent to the workbook open in Excel. The browser preview uses synthetic data and never opens a real workbook.

The terminal does not connect

  1. Invoke the installed Pair skill in the terminal and check its named profile with node scripts/session.mjs status --name NAME.
  2. Click Reconnect in Excel. If another pane is connected to the same terminal, disconnect it first.
  3. Check that the terminal can reach the relay over WSS. Development connections use loopback WS.
  4. If storage was cleared or a credential was forgotten, perform the one-time association again.

Connected, but no reply

The bridge is the connection, while your harness supplies the agent. Resume the Pair skill so that it consumes chat messages and sends replies. Background waiting depends on the harness's limits.

A change is waiting

Review the before/after preview and approve or reject it in Excel. Approval is required by default. Automatic approval applies to the current connection only.

A request timed out

Read the affected range before retrying a write. A change may have completed even when the reply was interrupted. Use the operation history to undo a completed change.

Reporting a problem

Include your operating system, Excel version, harness version, exact error and steps using synthetic data. Remove pairing URLs, tokens, workbook contents and model credentials. For self-hosted deployments, send the report to your deployment maintainer.
